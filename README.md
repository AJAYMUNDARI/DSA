# 📚 Data Structures & Algorithms in Python

## 📌 Overview

This repository documents my learning journey in **Data Structures & Algorithms (DSA)** using Python. It contains structured implementations of fundamental data structures, algorithmic techniques, and practice exercises commonly used in coding interviews and software development.

The repository is organized chapter-wise, with each topic including Python implementations, explanations, and practice problems to strengthen problem-solving skills.
